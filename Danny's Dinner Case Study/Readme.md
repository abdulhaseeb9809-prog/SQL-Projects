# Danny's Diner - SQL Case Study

## 📌 Overview
This case study analyzes customer behavior and spending patterns for Danny's Diner.

## 📊 Tables
- sales
- menu
- members

## 🛠 Concepts Used
- Joins
- Aggregations
- CTE
- Window Functions
- Ranking

## 📈 Key Insights
- Customer A spent the highest amount.
- Ramen was the most popular item.
- Loyalty program increased repeat visits.
