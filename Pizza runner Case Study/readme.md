# 🍕 Pizza Runner - SQL Case Study

## 📌 Overview
This case study focuses on analyzing a pizza delivery business to evaluate runner performance, delivery efficiency, and customer ordering patterns.

## 📊 Tables Used
- runners
- customer_orders
- runner_orders
- pizza_names
- pizza_recipes
- pizza_toppings

## 🛠 Concepts Demonstrated
- Data Cleaning
- Handling NULL & String 'null'
- CTE
- Window Functions
- Aggregations
- Case Statements
- Business KPI Calculation

## 📈 Key Insights
- Total pizzas delivered
- Average delivery time
- Most popular pizza
- Runner efficiency
- Cancellation rate
